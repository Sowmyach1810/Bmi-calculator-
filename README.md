BMI Calculator

A simple and responsive BMI (Body Mass Index) Calculator built using HTML, CSS, and JavaScript.

Features

- Calculates BMI using height and weight
- Displays BMI value with two decimal places
- Shows BMI category
- Input validation for empty and invalid values
- Simple and responsive user interface

BMI Categories

- Below 18.5 – Underweight
- 18.5 to 24.9 – Normal weight
- 25 to 29.9 – Overweight
- 30 and above – Obese

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Use

1. Enter your height in centimeters.
2. Enter your weight in kilograms.
3. Click the Calculate BMI button.
4. View your BMI result and category.

Formula

BMI = Weight (kg) / Height (m)²
